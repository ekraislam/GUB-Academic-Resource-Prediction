Prototype System

GUB Academic AI

Academic Resource Demand Prediction & Planning System

A machine learning prototype designed to help Green University of Bangladesh (GUB) anticipate academic resource demands — supporting smarter planning for classrooms, lab facilities, sections, and instructors.

Dataset Disclaimer

This application uses a completely synthetic, representative dataset. The data was programmatically generated to simulate realistic academic patterns (enrollment trends, course popularity, resource usage, etc.) and does NOT contain any real, confidential, or official Green University of Bangladesh institutional data. No student names, IDs, phone numbers, or personally identifiable information are present anywhere in this system.

The dataset is intended solely as a demonstration of the machine learning methodology. Any resemblance to actual course or institutional data is coincidental.

Project Objectives

Predict academic resource demand (LOW/MEDIUM/HIGH) using multi-class ML classification.

Provide data-driven recommendations for section planning, room allocation, and lab scheduling.

Compare multiple ML algorithms and automatically select the best performer.

Demonstrate a complete end-to-end ML pipeline suitable for university academic planning.

ML Methodology

01
Dataset Generation

5,000 synthetic records with 16 features engineered for logical consistency.

02
Preprocessing

LabelEncoding for categoricals; StandardScaler for numeric features; stratified train/test split (80/20).

03
Model Training

Six algorithms trained: Logistic Regression, KNN, Naive Bayes, Decision Tree, Random Forest, SVM.

04
Evaluation & Selection

Evaluated by Accuracy, Precision, Recall, F1-Score, and Confusion Matrix. Best model selected by weighted F1.

05
Deployment & Inference

Best model + preprocessors saved with Joblib, served via Flask web application.

Algorithms Used

  • Logistic Regression
  • K-Nearest Neighbors (KNN)
  • Gaussian Naive Bayes
  • Decision Tree
  • Random Forest
  • Support Vector Machine (SVM)

Evaluation Metrics

  • Accuracy — overall correct predictions
  • Precision — correct positive rate
  • Recall — true positive capture rate
  • F1-Score — harmonic mean of P & R
  • Confusion Matrix — per-class breakdown

Current Limitations

  • Dataset is synthetic; results may differ with real GUB data.
  • No temporal/time-series modelling (semester sequence not exploited).
  • Hyperparameters are not exhaustively tuned (no GridSearchCV).
  • No cross-validation (single train/test split used).
  • Recommendation engine is rule-based, not a learned model.

Future Improvements

  • Integrate actual GUB institutional data (with proper consent).
  • Add cross-validation and hyperparameter tuning (GridSearchCV).
  • Deploy SHAP/LIME explainability for per-prediction feature importance.
  • Implement time-series forecasting for multi-semester planning.
  • Build admin panel for uploading new data and re-training.
  • Add export-to-PDF/CSV for planning reports.
