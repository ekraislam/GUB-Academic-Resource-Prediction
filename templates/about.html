Project Story & Architecture

About GUB Academic AI

An intelligent academic planning prototype system designed for Green University of Bangladesh to predict course resource demand, optimize section scheduling, and support institutional decision-making.

Dataset Disclaimer
SYNTHETIC DATA PROTOTYPE
Synthetic Data Disclaimer: This prototype uses synthetic/representative academic data and does not contain official or confidential GUB institutional data. All course attributes, historical enrollment headcount, pass rates, and resource metrics are synthetically synthesized strictly for predictive analytics demonstration and machine learning model validation.
Problem Statement

University academic departments frequently face challenges in anticipating course enrollment spikes, leading to classroom overcrowding, underutilized lab facilities, section scheduling conflicts, and last-minute instructor assignments.

AI Machine Learning Solution

GUB Academic AI leverages machine learning to process 16 key academic parameters and accurately predict course demand (LOW / MEDIUM / HIGH). It automatically calculates section requirements, recommended room capacities, and resource allocation priorities.

System Limitations
  • • Prototype utilizes synthetically generated dataset rather than live institutional database records.
  • • Predictive engine currently uses a fixed 80/20 train/test evaluation split.
  • • Planning recommendations follow rule-based heuristics derived from ML predictions.
Future Enhancements
  • • Live integration with Green University ERP and Student Information Systems (SIS).
  • • Model explainability integration (SHAP & LIME feature importance visualization).
  • • Automated schedule generator for section and classroom room matching.
